## What is Me 2?

**Me 2** is an intelligent AI agent platform that creates your digital twin — an AI that truly understands you. Through natural conversations, Me 2 automatically learns about your preferences, experiences, goals, and personality, becoming your personal assistant and digital representation.

Think of Me 2 as **your AI clone** that:
- Converses naturally with you and learns from every interaction
- Automatically extracts and categorizes memories from conversations
- Generates comprehensive profiles that evolve over time
- Responds in real-time through WebSocket connections
- Provides APIs for seamless integration into your applications

## Key Features

### Conversational AI Intelligence
Engage in natural, context-aware conversations. Me 2 understands your history, preferences, and context to provide personalized responses.

### Memory Management and Dynamic Profile Generation
Me 2 combines intelligent memory extraction with automatic profile generation:

**Memory Management**: No manual data entry required. Me 2 automatically:
- Extracts key information from conversations
- Classifies memories (education, work, preferences, goals, experiences)
- Builds a structured knowledge base about you

**Profile Generation**: Your AI profile is automatically generated and updated based on accumulated memories. The profile evolves as you have more conversations, with components dynamically generated to reflect your unique characteristics and experiences.

### Real-time Communication
WebSocket-powered instant updates:
- Live conversation streaming
- Typing indicators
- Automatic profile update notifications

### Scalable Three-Tier Architecture
Built for developers with a clean separation of concerns:
- **Frontend**: Next.js web application (Progressive Web App)
- **Backend**: Node.js Express API with WebSocket server
- **AI Service**: Python FastAPI with LangChain integration
