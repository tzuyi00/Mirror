## Introduction

Me 2 provides a suite of APIs that enable developers to integrate conversational AI capabilities into their applications. Our APIs are designed to be simple, powerful, and scalable.

## API Categories

These APIs are available for external developers to integrate Me 2's conversational capabilities:

- [Chat API](/docs/api-reference/chatMessage) - Core conversational AI functionality
- [Thread API](/docs/api-reference/createThread) - Manage conversation threads
- [Profile API](/docs/api-reference/getProfileViews) - Access user profile views and information
- [Memory API](/docs/api-reference/getMemory) - Retrieve and access user memories from conversations
