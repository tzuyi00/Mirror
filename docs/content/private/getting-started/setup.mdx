---

## Prerequisites

- Node.js 18 or higher
- Python 3.10-3.12
- Poetry (Python package manager)
- PostgreSQL 14 or higher

## Frontend (Next.js)

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Visit http://localhost:3000 to use the app.

## Backend (Server)

1. Go to the `server` folder:
   ```bash
   cd server
   ```

2. Install backend dependencies:
   ```bash
   npm install
   ```

3. Generate Prisma Client (Development):
   ```bash
   npm run prisma:generate:dev
   ```

4. Apply Database Migrations (Development):
   ```bash
   npm run db:dev
   ```

5. Start the backend server:
   ```bash
   npm run dev
   ```

6. The server will be available at http://localhost:3001

## AI Server

1. Go to the `ai_server` folder:
   ```bash
   cd ai_server
   ```

2. Install Python dependencies (via Poetry):
   ```bash
   poetry install --no-root
   ```

3. Start the AI inference server::
   ```bash
   poetry run python main.py
   ```

4. The AI server will be available at http://localhost:8000
